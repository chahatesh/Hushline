# Community code of conduct

Be respectful, patient, and constructive. Welcome people of different backgrounds and abilities. Critique ideas and code without attacking people. Do not harass, threaten, discriminate, share private information without permission, or post sexual or hateful material.

Maintainers may remove harmful content and restrict participation when necessary, explaining decisions where appropriate. Apply these expectations in project issues, pull requests, discussions, and other project spaces. Report concerns privately using the GitHub profile contact options of the repository owner, Chahatesh. Do not publish sensitive reports in an issue.
